Common Debugging Workflows

Debugging this browser is easiest when every investigation follows the pipeline. Start from the visible symptom, then walk backward until the first wrong representation appears.

The goal is to avoid guessing. Screenshots, telemetry, fixtures, and focused tests should point to the responsible layer.

Workflow: Page Does Not Load

Check:

  • URL normalization.
  • main document request.
  • final URL after redirects.
  • response status.
  • body size and content type.
  • parser start.
  • tab state update.

If the body never arrived, do not inspect CSS yet. If the body arrived but parsing failed, reduce the HTML.

Workflow: Page Loads But Looks Wrong

Check:

  • stylesheet discovery,
  • stylesheet loading,
  • selector matching,
  • computed style,
  • layout boxes,
  • render graph objects,
  • canvas painting.

Create a color layout fixture when the issue is structural. Use a screenshot when the issue is visual.

Workflow: Text Or Links Are Wrong

Check:

  • source HTML spaces around tags,
  • parser text nodes,
  • inline style and display,
  • rich text spans,
  • line layout,
  • link hit boxes,
  • copied text output.

If copied text contains visual line wraps as newlines, inspect selection reconstruction rather than paragraph layout.

Workflow: Dynamic Content Missing

Check:

  • script resource loaded,
  • script executed,
  • exception or timeout,
  • host API support,
  • emitted browser effect,
  • style/layout invalidation,
  • repaint.

If a page works after waiting longer, inspect timers and late resource scheduling.

Workflow: Images Missing

Check:

  • image URL extraction,
  • URL resolution,
  • request scheduling,
  • duplicate or collision policy,
  • response status,
  • decode result,
  • placeholder replacement.

Use the network graph script when request timing matters.

Rust Shape

Debugging is easier when every pipeline boundary can produce a compact snapshot.

struct DebugSnapshot {
    page_id: PageId,
    url: String,
    loaded_resources: usize,
    node_count: usize,
    styled_node_count: usize,
    layout_box_count: usize,
    render_object_count: usize,
}

fn snapshot_page(page: &PageState) -> DebugSnapshot {
    DebugSnapshot {
        page_id: page.id,
        url: page.url.clone(),
        loaded_resources: page.resources.len(),
        node_count: page.document.node_count(),
        styled_node_count: page.styles.len(),
        layout_box_count: page.layout_box_count(),
        render_object_count: page.render_object_count(),
    }
}

A snapshot will not solve the bug by itself, but it quickly shows which stage stopped producing output.
